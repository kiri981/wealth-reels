# wealth-reels

Automatisch erzeugte Gold-Reels (XAUUSD) für Wealth Club.

- `factory/` – Reel-Generator (`python3 factory/factory.py spec.json out.mp4`)
- `specs/` – Inhalt je Tag (JSON)
- `reels/` – fertige Videos; der Bot holt sie über die öffentliche Raw-URL ab

Keine Anlageberatung. Trading birgt Verlustrisiken.
